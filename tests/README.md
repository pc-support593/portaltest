# 自動テスト(反映前の一括確認)

```
npm test            # 3種類をまとめて実行(約1〜2分)
node tests/unit.js  # 計算ロジックだけ(数秒)
```

| ファイル | 確認すること | 必要なもの |
|---|---|---|
| unit.js | 名前(姓 名・会社名の除去)、入社日(日本時間)、五十音順・メンバー順、時間制限、週の始まり・予定の割り当て | Node のみ |
| api.js | 添付ファイルの許可/拒否・サイズ・削除、お知らせの固定、基本のAPI | Node のみ |
| browser.js | 全ページの表示、PC(1280px)・スマホ(390px)で横にはみ出さない、スマホのメニュー、お知らせの並び・NEW、週の予定、スタッフ予定のタブ、通信失敗・無応答時の表示 | Microsoft Edge(見つからなければ省略。`EDGE_PATH` で指定可) |

- サーバーは一時フォルダにコピーして **devモード・空のDB** で起動する。本物の `data/portal.db` には触らない。
- 実際の会社のMS365(Graph)のデータでの表示は再現できない。テスト環境での目視確認は別に必要。
- 画面のコードを変えたら、期待値(`browser.js` の並び順・文言など)も合わせて直す。
- 反映前に手元(テスト環境側)で実行する。本番サーバーでは実行しない。テスト用サーバーには `JINJER_*`・`IGRACE_*`・`TENANT_ID`・`CLIENT_ID`・`ENABLE_DAYOFFS` を引き継がない(外部へ接続しない)。
- Edge が無い環境では画面の確認(browser.js)は SKIP になり、一括実行の結果にも SKIP と表示される。
